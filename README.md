# NetiShield Run

بازی آرکید Runner دوبعدی با هویت بصری نئونی **NetiShield**، متصل به ربات تلگرام از طریق **پلتفرم رسمی Telegram Games** (`sendGame`).

> **بدون** استفاده از Telegram Mini App / Web App.  
> **بدون** فرضیه در مورد HTMLBubbles یا قابلیت‌های آزمایشی.

## 1. محدودیت‌های مهم API

طبق مستندات رسمی Telegram Bot API:

| موضوع | وضعیت |
|--------|--------|
| `sendGame` به چت خصوصی | ✅ پشتیبانی می‌شود |
| `sendGame` به گروه / سوپرگروه | ✅ پشتیبانی می‌شود |
| `sendGame` به کانال | ❌ **پشتیبانی نمی‌شود** (خطای صریح API) |
| فوروارد دستی پیام بازی توسط کاربر | ✅ امکان‌پذیر است |
| Mini App / Web App | در این پروژه عمداً استفاده نشده |
| HTMLBubbles | قابلیت عمومی/مستند برای این کاربرد نیست |

**نتیجه:** ربات نمی‌تواند مستقیماً پیام Game را به کانال بفرستد. مدیر باید پیام بازی را از چت خصوصی دریافت کند و به‌صورت دستی به کانال فوروارد کند. این محدودیت API است، نه باگ کد.

## 4. راه‌اندازی بازی (Hosting)

فایل‌های داخل پوشه `game/` باید روی یک دامنه **HTTPS** در دسترس باشند.

مثال ساختار روی سرور:

```
https://your-domain.com/game/index.html
https://your-domain.com/game/style.css
https://your-domain.com/game/game.js
```

یا ریشه:

```
https://games.your-domain.com/
```

**نکات:**

- فقط HTTPS (گواهی معتبر)
- بدون نیاز به CDN خارجی برای اجرای بازی (صدا با Web Audio تولید می‌شود)
- CORS در حالت عادی برای iframe تلگرام مشکلی ایجاد نمی‌کند

مقدار `GAME_URL` در `.env` باید دقیقاً به همین آدرس اشاره کند (مثلاً `https://your-domain.com/game`).

---

## 5. ثبت بازی در BotFather

1. به [@BotFather](https://t.me/BotFather) بروید.
2. اگر ربات ندارید: `/newbot` و مراحل را طی کنید و **Token** را ذخیره کنید.
3. دستور `/newgame` را بفرستید.
4. ربات مورد نظر را انتخاب کنید.
5. عنوان بازی را وارد کنید (مثلاً `NetiShield Run`).
6. توضیحات کوتاه بنویسید.
7. تصویر کاور (پیشنهادی حدود 640×360) آپلود کنید.
8. (اختیاری) GIF گیم‌پلی آپلود کنید.
9. **Short name** را وارد کنید (مثلاً `netishieldrun`) — فقط حروف، عدد، `_` ، طول 3–30.
10. Short name را در `.env` به‌عنوان `GAME_SHORT_NAME` قرار دهید.

سپس با `/setgames` یا بخش Edit games می‌توانید **URL** بازی را تنظیم کنید (همان `GAME_URL`).

> بعد از ثبت، لینک تست شبیه این است:  
> `https://t.me/YourBot?game=netishieldrun`

## 6. راه‌اندازی ربات

```bash
# کلون / کپی پروژه
cd netishield-run

# نصب وابستگی‌ها
npm install

# ساخت فایل محیط
cp .env.example .env
# سپس .env را با ویرایشگر باز کنید و مقادیر را پر کنید
```

نمونه `.env`:

```env
BOT_TOKEN=123456:ABC-DEF...
GAME_SHORT_NAME=netishieldrun
GAME_URL=https://your-domain.com/game
ADMIN_IDS=123456789
CHANNEL_ID=@YourChannel
```

اجرا:

```bash
npm start
```

ربات با **Long Polling** بالا می‌آید. برای production می‌توانید بعداً Webhook تنظیم کنید (در این نسخه long polling کافی و ساده‌تر است).

## 8. ارسال / فوروارد به کانال

### روش رسمی و پشتیبانی‌شده

1. مدیر در چت خصوصی با ربات `/sendgame` یا `/game` را می‌زند.
2. پیام Game دریافت می‌شود.
3. پیام را **دستی** به کانال فوروارد می‌کند.

### چرا ربات نمی‌تواند مستقیم به کانال بفرستد؟

طبق مستندات و رفتار واقعی API:

```
Bad Request: Games can't be sent to channel chats
```

این محدودیت سمت تلگرام است. کد ربات این خطا را مدیریت می‌کند و پیام مناسب نمایش می‌دهد.

### راهکار جایگزین

- استفاده از یک **گروه** به‌عنوان واسط (ربات در گروه `sendGame` کند، سپس ادمین فوروارد کند).
- یا پست متنی/رسانه‌ای در کانال با لینک `https://t.me/YourBot?game=netishieldrun` (این پیام از نوع Game نیست، اما کاربران را به بازی هدایت می‌کند).

**هیچ‌گاه در این پروژه ادعا نشده که `sendGame` به کانال بدون تست واقعی کار می‌کند.** در واقع طبق API کار نمی‌کند.

## 9. High Scores

- `setGameScore` و `getGameHighScores` توسط Bot API پشتیبانی می‌شوند.
- امتیاز **به‌ازای هر پیام بازی / هر چت** ذخیره می‌شود.
- کلاینت بازی **نباید** توکن ربات را داشته باشد.
- برای ثبت امتیاز رسمی تلگرام باید یک endpoint امن روی سرور داشته باشید که از بازی درخواست بگیرد، اعتبارسنجی کند، سپس `setGameScore` را صدا بزند.

نسخه فعلی بازی رکورد را به‌صورت محلی (`localStorage`) نگه می‌دارد و دکمه Share Score از `TelegramGameProxy.shareScore()` استفاده می‌کند (فقط داخل کلاینت تلگرام فعال است).

## 10. تست

### بازی

| مورد | انتظار |
|------|--------|
| اجرا در مرورگر موبایل (Android/iOS) | Canvas + لمس برای پرش |
| Telegram Desktop | باز شدن در پنجره بازی |
| دکمه Jump روی صفحه | پرش |
| Pause / Resume | توقف و ادامه |
| Lives = 3 | برخورد → کم شدن جان |
| Game Over | نمایش امتیاز و Best |
| Restart | شروع مجدد |
| صدا | روشن/خاموش |

### ربات

| مورد | انتظار |
|------|--------|
| `/game` در خصوصی | پیام Game با دکمه Play |
| فشردن Play | callback → باز شدن `GAME_URL` |
| `/game` در کانال (اگر ممکن باشد) | خطای API و پیام راهنما |
| `/sendgame` توسط غیرمدیر | رد دسترسی |
| فوروارد دستی پیام Game به کانال | وابسته به کلاینت کاربر؛ معمولاً کار می‌کند |

> تست واقعی فوروارد و اجرای بازی بعد از فوروارد باید روی حساب و کانال واقعی شما انجام شود. این محیط توسعه تضمین runtime روی سرور تلگرام شما را ندارد.

## 11. استقرار روی Chabokan

1. پروژه را روی سرور Linux قرار دهید.
2. Node.js 18+ نصب باشد.
3. `npm install`
4. فایل `.env` را با مقادیر واقعی بسازید.
5. بازی را روی یک دامنه HTTPS (می‌تواند همان سرور یا CDN جدا) سرو کنید.
6. `npm start` یا با process manager (pm2 / systemd):

```bash
# مثال با pm2
npm install -g pm2
pm2 start bot/bot.js --name netishield-run
pm2 save
```

از Docker در این پروژه استفاده نشده است (طبق درخواست).

## 12. گزارش محدودیت‌ها

### Telegram Games در برابر Mini App / Web App

| ویژگی | Telegram Games | Mini App / Web App |
|--------|----------------|---------------------|
| متد ارسال | `sendGame` | `InlineKeyboard` با `web_app` |
| ثبت | `/newgame` در BotFather | `/newapp` |
| باز شدن | در محیط بازی تلگرام | WebView اپ |
| High Score رسمی | `setGameScore` | خیر (باید خودتان بسازید) |
| ارسال به کانال | ❌ | دکمه Web App در کانال ممکن است |

این پروژه عمداً فقط مسیر **Games** را پیاده کرده است.

### HTMLBubbles

قابلیت عمومی و مستند Bot API با نام HTMLBubbles برای جایگزین کردن `sendGame` در این سناریو وجود ندارد. هر ادعایی در این مورد خارج از مستندات رسمی است و در این پروژه استفاده / فرض نشده است.
